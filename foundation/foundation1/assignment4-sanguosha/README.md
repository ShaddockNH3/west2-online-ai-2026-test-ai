# 三国杀 demo（Foundation 1 作业 4）

一个 4 人身份局的命令行三国杀：你扮演主公，与三名 AI（忠臣、反贼、内奸）对战。
四大阵营各派一名武将，基础牌与锦囊牌齐全，**不包含装备牌**。

## 运行

```zsh
cd foundation/foundation1/assignment4-sanguosha
python main.py            # 随机开局
python main.py --seed 7   # 固定随机种子，可复现
```

## 目录结构

| 文件 | 职责 |
| --- | --- |
| `main.py` | 入口：发身份、抽武将、开局 |
| `game.py` | 引擎：回合流程、牌结算、技能分发、AI、胜负 |
| `player.py` | 玩家状态（体力、手牌、回合内标记） |
| `cards.py` | 牌与牌堆（基础牌 + 锦囊牌，带花色与颜色） |
| `generals.py` | 16 名武将的数据与技能说明 |

## 身份与胜负

- 主公（人类玩家）+ 忠臣：目标是消灭反贼与内奸；
- 反贼：目标是杀死主公；
- 内奸：先除掉所有人，最后与主公单挑。

判定规则与标准版一致：主公阵亡时，若场上只剩内奸则内奸胜，否则反贼胜；
反贼与内奸全部阵亡则主公方胜。击杀反贼奖励摸三张牌。

## 牌堆（84 张，无装备）

- 基础牌：杀 ×24、闪 ×16、桃 ×8、酒 ×4
- 锦囊：无中生有 ×4、过河拆桥 ×6、顺手牵羊 ×5、决斗 ×4、
  南蛮入侵 ×3、万箭齐发 ×1、桃园结义 ×1、无懈可击 ×4

每张牌都带花色，红桃/方块为红色、黑桃/梅花为黑色，
武圣、奇袭、急救三个技能都依赖颜色。

## 主要规则实现

- **距离**：按座位顺/逆时针数存活玩家的最小间隔，杀与顺手牵羊的范围为 1；
- **杀**：每回合限一次（咆哮除外），酒可让下一张杀 +1 伤害；
- **闪**：被杀指定时打出；吕布在场时需要两张；
- **桃**：出牌阶段回自己的血；濒死时从濒死角色开始按座位顺序向所有人求桃，
  华佗可以用红色手牌响应（急救）；
- **决斗**：双方轮流出杀（武圣的红色牌可代），先不出的一方受 1 点伤害，
  发起者有无双时对手一次要出两张；
- **南蛮入侵 / 万箭齐发**：对所有其他角色依次结算，出杀 / 出闪否则受 1 点伤害；
- **无懈可击**：锦囊生效前依次询问所有玩家，可以反制无懈（最多嵌套三层），
  AI 只保护自己人和队友；
- **弃牌阶段**：手牌上限 = 当前体力，吕蒙未出杀时跳过（克己）。

## 有意简化的部分

1. **AI 知晓所有身份**。真实的身份局需要推理，这超出了本作业「面向对象语法练习」的范围；
2. **没有装备与延时锦囊**，因此没有判定阶段，鬼才、鬼道这类改判技能随之省略；
3. **雷击是简化版**：原版需要判定，这里改成 50% 概率直接造成 1 点雷电伤害；
4. **酒不能在濒死时当桃**，只能作为出牌阶段的增益；
5. **主公处刑忠臣的惩罚**未实现；
6. **AI 策略是启发式的**：濒死吃桃、卖血将（青囊）救残血队友、
   优先杀血量最少且在攻击范围内的敌人、锦囊按「收益确定性」排序使用。

## 操作说明

轮到你时：

1. 输入手牌编号使用该牌（杀、锦囊会追问目标，输入 0 可取消）；
2. 输入 `s` 打开技能菜单（制衡、苦肉、青囊、离间、仁德、武圣、奇袭会按武将自动出现）；
3. 输入 `e` 结束出牌阶段。

被杀指定、被求桃、被询问无懈可击时，会分别提示你打出闪或回答 y/n。
